{% trans "Irradiación con electrones de hasta 2 MeV y radiación Bremsstrahlung" %}

{% trans "Descripción del Equipo" %}

{% blocktrans trimmed %} El acelerador de electrones, tipo Van de Graaff, permite la irradiación de materiales con electrones de hasta 2 MeV de energía, así como con la radiación Bremsstrahlung producida por el frenado del haz, con corrientes de hasta 150 µA. {% endblocktrans %}

{% blocktrans trimmed %} De esta manera se simula la radiación de fuentes de Co-60, con la ventaja de posibilitar irradiaciones rápidas (tasas de dosis más altas y mejor controladas) y realizar medidas durante irradiación in-situ. {% endblocktrans %}

{% trans "Parámetros Controlados y Flexibilidad" %}

{% blocktrans trimmed %} Temperatura, vacío, gas de trabajo, tasa de dosis y energía del haz están estrictamente controlados. Es posible irradiar componentes relativamente grandes. El personal responsable puede diseñar y desarrollar cámaras experimentales adaptadas a cada ensayo. {% endblocktrans %}

{% blocktrans trimmed %} Instalación altamente flexible con sistemas in-beam únicos para medir conductividad eléctrica, pérdidas dieléctricas, permitividad (Hz→GHz) y propiedades ópticas durante la irradiación. Las irradiaciones pueden realizarse en alto vacío, aire o atmósfera controlada (N2, He). {% endblocktrans %}

{% trans "Características del Haz" %}

  • {% trans "Energía" %}0.25 – 2.0 MeV
  • {% trans "Corriente" %}10 pA – 150 µA
  • {% trans "Tamaño de muestra" %}3 mm² hasta 20×20 cm²
  • {% trans "Área haz desfocalizado" %}1 cm
  • {% trans "Focalización" %}hasta 1 mm de diámetro
  • {% trans "Desfocalización" %}hasta 3 cm de diámetro
  • {% trans "Barrido" %}hasta 20×20 cm²
  • {% trans "Tasa de dosis máxima" %}105 Gy/s

{% trans "Capacidad de Medidas In-Situ" %}

{% blocktrans trimmed %} Se han realizado numerosos estudios en aislantes candidatos para fusión, donde se requieren pocos dpa (típicamente entre 10-12 y 10-8 dpa/s) y tasas de radiación (Bremsstrahlung o directa) de hasta 104 Gy/s. Durante la irradiación se han medido propiedades ópticas y eléctricas, además de difusión de He y H. {% endblocktrans %}

{% blocktrans trimmed %} Estos sistemas permiten medidas simultáneas de propiedades ópticas, eléctricas y dieléctricas desde Hz hasta GHz. También hay sistemas en línea para medir absorción óptica y radioluminiscencia durante la irradiación. Para estos estudios se diseñan y fabrican cámaras y portamuestras a medida en los talleros del CIEMAT. {% endblocktrans %}
