{% trans "Implantador de Iones Danfysik" %}

{% blocktrans trimmed %} 60 keV para estudios de fusión con H, He y D {% endblocktrans %}

{% trans "Descripción del Equipo" %}

{% blocktrans trimmed %} El implantador de iones Danfysik de 60 keV permite la implantación iónica con especies gaseosas como helio, hidrógeno y deuterio, entre otras, principalmente para estudios relacionados con la investigación de fusión. {% endblocktrans %}

{% blocktrans trimmed %} El equipo del implantador ha diseñado y desarrollado una variedad de cámaras de irradiación y configuraciones experimentales adaptadas a necesidades de investigación específicas. Por ejemplo, se pueden realizar mediciones simultáneas de ionoluminiscencia y conductividad eléctrica superficial, permitiendo la correlación directa entre la degradación macroscópica del material y la generación de defectos durante la implantación. {% endblocktrans %}

{% trans "Aplicaciones y Experiencias" %}

{% blocktrans trimmed %} La instalación ha sido ampliamente utilizada para implantar iones de H, He y D tanto en metales como en aislantes para la evaluación de degradación microestructural superficial, ionoluminiscencia y degradación eléctrica, así como para implantar isótopos de helio e hidrógeno para experimentos de difusión y desorción. {% endblocktrans %}

{% blocktrans trimmed %} Los experimentos pueden realizarse bajo temperaturas controladas que van desde temperatura ambiente hasta 800 °C. Las cámaras de irradiación especializadas y los portamuestras son diseñados por el equipo del implantador y fabricados en los talleres del CIEMAT para soportar una amplia variedad de requisitos experimentales. {% endblocktrans %}

{% trans "Investigación en Fusión" %}

{% blocktrans trimmed %} Este equipo es fundamental para la investigación en materiales para fusión, permitiendo simular las condiciones de irradiación que experimentarán los materiales en reactores de fusión. La capacidad de trabajar con isótopos de hidrógeno y helio es crucial para entender el comportamiento de los materiales bajo irradiación de partículas ligeras. {% endblocktrans %}

{% blocktrans trimmed %} La flexibilidad del sistema permite adaptar las condiciones experimentales a necesidades específicas de investigación, desde estudios básicos de daño por irradiación hasta evaluaciones de materiales candidatos para aplicaciones de fusión. {% endblocktrans %}
