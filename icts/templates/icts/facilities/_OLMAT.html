{% trans "Dispositivo HHF OLMAT" %}

{% blocktrans trimmed %} Optimización de blancos avanzados de metal líquido para ensayos de alta carga térmica {% endblocktrans %}

{% trans "Visión general" %}

{% blocktrans trimmed %} OLMAT es el banco de ensayos de referencia del CIEMAT para la calificación de materiales sometidos a flujos térmicos extremos mediante haces NBI y láser. La instalación está abierta a colaboraciones de centros públicos y privados en ámbitos de física, ingeniería mecánica y ciencia de materiales. {% endblocktrans %}

{% blocktrans trimmed %} El banco permite combinar calentamiento convectivo con cargas radiativas controladas, registrar los fenómenos transitorios con instrumentación de alta velocidad y realizar ajustes personalizados en la preparación de muestras para cada campaña experimental. {% endblocktrans %}

{% trans "Capacidades principales" %}

  • {% trans "Modos de haz" %}NBI, láser o disparos combinados
  • {% trans "Escala temporal" %}Resolución de 1 ms en termografía y pirometría
  • {% trans "Supervisión" %}Cámara rápida y espectroscopía óptica sincronizada
  • {% trans "Entorno de ensayo" %}Preparación y acondicionamiento en laboratorio dedicado
  • {% trans "Muestreo" %}Diseño a medida de portamuestras y mojado de metal líquido

{% trans "Diagnósticos disponibles" %}

  • {% trans "Termopares embebidos" %}
  • {% trans "Pirometría infrarroja" %}
  • {% trans "Termografía IR (1 ms)" %}
  • {% trans "Cámara rápida de alta velocidad" %}
  • {% trans "Espectroscopia óptica" %}
  • {% trans "Sondas Langmuir" %}

{% blocktrans trimmed %} El laboratorio OLMAT ofrece soporte para recubrimientos de metales líquidos, diseño de portamuestras y servicios de preparación previos a la campaña experimental. {% endblocktrans %}
