{% blocktrans trimmed %} Bruker Dektak XT para medición de rugosidad y espesores {% endblocktrans %}

{% trans "Descripción del Equipo" %}

{% blocktrans trimmed %} El perfilómetro Bruker Dektak XT es un instrumento de medición de superficie por contacto que permite caracterizar la topografía, rugosidad y espesores de capas delgadas con resolución nanométrica. {% endblocktrans %}

{% blocktrans trimmed %} Mediante un palpador de diamante que se desplaza sobre la superficie de la muestra, el equipo registra variaciones verticales con alta precisión, proporcionando perfiles topográficos detallados y parámetros de rugosidad estandarizados. {% endblocktrans %}

{% trans "Características Técnicas" %}

  • {% trans "Resolución vertical" %}1 Å (0.1 nm)
  • {% trans "Rango vertical" %}hasta 1 mm
  • {% trans "Longitud de barrido" %}hasta 55 mm
  • {% trans "Radio palpador" %}2 µm, 5 µm, 12.5 µm
  • {% trans "Fuerza de medición" %}1 mg a 15 mg
  • {% trans "Tamaño de muestra" %}hasta 200 mm de diámetro
  • {% trans "Peso máximo muestra" %}hasta 6.8 kg

{% trans "Tipos de Mediciones" %}

{% trans "Rugosidad Superficial" %}

{% blocktrans trimmed %} Determinación de parámetros de rugosidad como Ra, Rq, Rz, Rmax según estándares internacionales. Análisis de texturas superficiales producidas por diferentes procesos de fabricación o tratamiento. {% endblocktrans %}

{% trans "Espesor de Capas" %}

{% blocktrans trimmed %} Medición precisa de espesores de recubrimientos y capas delgadas mediante la técnica de escalón (step). Ideal para control de procesos de deposición como PVD, CVD, pulverización catódica, etc. {% endblocktrans %}

{% trans "Análisis de Formas" %}

{% blocktrans trimmed %} Caracterización de estructuras micro y nanométricas: surcos, canales, patrones grabados, desgaste superficial. Obtención de perfiles 2D detallados de características topográficas. {% endblocktrans %}

{% trans "Aplicaciones Principales" %}

{% blocktrans trimmed %} El perfilómetro es una herramienta esencial para el control de calidad en procesos de fabricación, caracterización de recubrimientos funcionales, análisis de desgaste y tribología, estudios de corrosión superficial, y verificación de procesos de micromecanizado. {% endblocktrans %}

{% blocktrans trimmed %} Su capacidad de medición por contacto lo hace especialmente útil para superficies que no son adecuadas para técnicas ópticas, como materiales transparentes, superficies de baja reflectividad o estructuras con altas pendientes. Es ampliamente utilizado en investigación de materiales, desarrollo de recubrimientos y caracterización de componentes para tecnología de fusión nuclear. {% endblocktrans %}
