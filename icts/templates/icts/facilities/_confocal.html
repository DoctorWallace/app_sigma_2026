{% trans "Descripción del Equipo" %}

{% blocktrans trimmed %} El microscopio confocal Sensofar S Neox es un sistema óptico de alta precisión que combina tres tecnologías complementarias: microscopía confocal, interferometría de luz blanca y perfilometría óptica. {% endblocktrans %}

{% blocktrans trimmed %} Este equipo permite realizar mediciones topográficas de superficies con resolución nanométrica, análisis de rugosidad, caracterización de texturas y evaluación dimensional de microestructuras de manera no destructiva. {% endblocktrans %}

  • {% trans "Resolución vertical" %}hasta 0.01 nm (interferometría)
  • {% trans "Resolución lateral" %}hasta 140 nm (confocal)
  • {% trans "Objetivos" %}2.5x, 5x, 10x, 20x, 50x, 100x, 150x
  • {% trans "Campo de medición" %}hasta 18 x 18 mm
  • {% trans "Rango de medición Z" %}hasta 10 mm
  • {% trans "Modos de medición" %}Confocal, Interferometría, Perfilometría
  • {% trans "Tipo de análisis" %}Rugosidad, topografía, dimensiones

{% trans "Técnicas de Medición" %}

{% trans "Microscopía Confocal" %}

{% blocktrans trimmed %} Ideal para superficies rugosas, proporcionando imágenes topográficas 3D con alta resolución lateral. Permite caracterizar texturas y patrones con escalas de rugosidad desde nanómetros hasta milímetros. {% endblocktrans %}

{% trans "Interferometría" %}

{% blocktrans trimmed %} Técnica de máxima precisión para superficies lisas y reflectantes. Proporciona resolución vertical subnanométrica, ideal para la caracterización de superficies pulidas y capas delgadas. {% endblocktrans %}

{% trans "Aplicaciones Principales" %}

{% blocktrans trimmed %} Este equipo es fundamental para la caracterización superficial de materiales en diversas áreas: materiales para fusión nuclear, recubrimientos funcionales, componentes micromecánicos, dispositivos ópticos y semiconductores. {% endblocktrans %}

{% blocktrans trimmed %} Permite el análisis de parámetros de rugosidad (Ra, Rq, Rz, etc.), medición de espesores de capas, caracterización de defectos superficiales, análisis de desgaste y evaluación de procesos de fabricación. La capacidad de realizar mediciones sin contacto evita daños en muestras delicadas. {% endblocktrans %}
