## 🎯 Lo Que Querías: Ver Qué Templates se Usan

### Solución Inmediata:

1. **Inicia el servidor:**
   ```bash
   python manage.py runserver
   ```

2. **Abre tu navegador:**
   ```
   http://127.0.0.1:8000/
   ```

3. **Mira la barra lateral derecha →**
   - Verás una toolbar con pestañas
   - Click en **"Templates"**
   - ¡Ahí están todos los templates que se usan!

**Ejemplo de lo que verás:**
```
Templates (3 rendered)
📄 templates/portal/home.html
   C:\Users\marce\Desktop\SIGMA_FUSION\templates\portal\home.html
   
📄 templates/base_icts.html (inherited)
   C:\Users\marce\Desktop\SIGMA_FUSION\templates\base_icts.html
```

**¡Ya no tendrás que buscar qué template es!** 🎉
