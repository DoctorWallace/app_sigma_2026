# LO3 operational checklist

Scope: manual UI/JS checks to validate the LO3 operational flow (Metrologia de superficies opticas 3D).

## Manual checklist (UI/JS)
- [ ] Crear propuesta ICTS con confocal y 3 muestras (identification/name/details). Guardar como borrador.
- [ ] Reabrir el borrador y confirmar que las 3 muestras confocal aparecen con datos completos.
- [ ] En la tecnica confocal, pulsar "Anadir muestra" y confirmar que se inserta en la tarjeta visible (no en el modal oculto).
- [ ] Portal LO3 > Solicitudes de analisis: crear sesion para la propuesta aceptada.
- [ ] Verificar que las 3 muestras importadas aparecen como "declaradas".
- [ ] Anadir una muestra extra (no declarada) y confirmar el badge "No declarada".
- [ ] Completar fechas minimas y medidas realizadas; finalizar sesion.
- [ ] Descargar Aviso PDF y Registro XLSX desde la sesion.
- [ ] Como solicitante: ir a Resultados LO3, ver la sesion y descargar PDF/XLSX.

## Acceptance criteria (gate)
- [ ] Editar borrador mantiene datos de tecnica, incluyendo muestras dinamicas.
- [ ] Resultados accesibles desde cuenta SIGMA ICTS; aviso PDF almacenado y descargable.
- [ ] Trazabilidad minima de recepcion/analisis/entrega completada al finalizar.
